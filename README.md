# Snapmatic VI

An in-game phone for Leonida. Shoot, edit, and post to the Vice Feed — a GTA VI-inspired experience built on [React Image Editor](https://github.com/unlayer/react-image-editor).

> Original work. Not affiliated with or endorsed by Rockstar Games. No Rockstar assets, characters, or trademarks are used.

## Status

In development for the Unlayer **Build with React Image Editor** challenge.

## Local setup

```bash
npm install
npm run dev
```


## Stack

React 18 · TypeScript · Vite · @unlayer/react-image-editor
